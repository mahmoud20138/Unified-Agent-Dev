# Accepted provider artifacts

This directory is empty in release 0.1.0 because no research candidate has passed the release gates.

An artifact is added here only after its exact digest, license disposition, security review, Windows evidence, runtime contract, and least-privilege permission contract are recorded in `catalog/acceptance-overrides.json`. The catalogue compiler rejects an accepted entry when any required evidence is missing, stale, malformed, or does not match the artifact bytes.
